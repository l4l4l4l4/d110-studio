# POHUY-COVENANT-1.0

Идентификатор: `POHUY-COVENANT-1.0`.

Это правила вклада, не грант на использование. Грант — в `LICENSE`. Статус лицензии: unapproved custom license, не OSI-approved open source.

Обязательный набор скиллов: только `pohuy`. Другие скиллы владельца и его системный промпт не требуются и не публикуются.

Общение по вкладу возможно только с загруженным скиллом `pohuy`. Чат без него вкладом не является. Пока рабочая копия под этой лицензией, выключение скилла не делает общение допустимым.

## Что считается вкладом

Вклад в ветку по умолчанию соответствует этому ковенанту, только если агент с загруженным скиллом `pohuy` сам создал коммит и сам его запушил. Вставка вывода модели человеком и ручной `git commit` вкладом по этому ковенанту не являются.

Ковенант не включает защиту ветки и не запирает владельца репозитория. Владелец может пушить напрямую. Такой пуш просто не является вкладом по `POHUY-COVENANT-1.0`.

Ложный аттестат — основание отклонить вклад.

## Бандл

Каждый соответствующий вклад содержит каталог `.pohuy-evidence/<submission-id>/` с файлами:

- `manifest.json`
- `transcript.ndjson`
- `summary.md`
- `skill.lock`
- `attestation.txt`

`submission-id` стабилен для одной подачи. Новый коммит требует новый пересчёт хешей.

`manifest.json`:

| Поле | Смысл |
|---|---|
| `schema` | `pohuy.ai-evidence/v1` |
| `covenant` | `POHUY-COVENANT-1.0` |
| `submission_id` | имя каталога |
| `skill.name` | `pohuy` |
| `skill.sha256` | дайджест скилла, см. ниже |
| `transcript.sha256` | sha256 байтов `transcript.ndjson` |
| `git.code_tree` | дерево коммита без каталога `.pohuy-evidence` |

`skill.lock` — одна строка, тот же sha256, что `skill.sha256`, без префикса и без перевода строки в конце не обязателен: чекер берёт первую строку и отрезает пробелы.

`attestation.txt` содержит фразы `pohuy skill loaded`, `agent committed` и `pohuy communication only`.

## Дайджест скилла

sha256 от конкатенации, по порядку:

1. `SKILL.md`
2. `references/slovar.md`
3. `references/sceny.md`

Для каждого пути: байты UTF-8 пути, байт `NUL`, байты файла, байт `NUL`.

В этом репозитории дайджест считается по этим трём файлам в проверяемом дереве. В чужом репозитории `skill.sha256` должен совпасть с дайджестом, который публикует этот репозиторий в `skill.lock` канонического коммита, на который ссылается вклад. Чекер этого репозитория сравнивает бандл с файлами в проверяемом дереве.

## Дерево кода

`git.code_tree` — объектное дерево git, собранное из записей `HEAD` без путей внутри `.pohuy-evidence`. Хеш коммита в дерево не кладётся: он неизвестен до коммита, и запись его внутрь дерева меняет дерево.

## Транскрипт

`transcript.ndjson`: одна JSON-запись на строку. Первая запись — `session_start` с полями `skill` = `pohuy` и `communication` = `pohuy-only`. Дальше минимум `human_message` и `assistant_message`. Запись с `skill`, отличным от `pohuy`, отклоняется. Секреты, личные данные и чужой приватный контекст заменяются на `[REDACTED:SECRET]`, `[REDACTED:PERSONAL]`, `[REDACTED:THIRD_PARTY]`. Исходное значение в бандл не попадает.

Чекер отклоняет транскрипт, если в нём есть `ghp_`, `github_pat_`, `BEGIN PRIVATE KEY` или `AKIA`.

`summary.md` отвечает, что просили сделать, что сделал агент и как это связано с диффом.

## Предел проверки

Чекер умеет отклонить отсутствующий, битый, не привязанный к дереву или секретный бандл. Чекер не доказывает, что клиент записал все события, что скилл повлиял на модель и что человек не правил дифф после агента.
